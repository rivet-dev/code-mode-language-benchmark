Write a JavaScript (Node.js 22) script for the task below. The script runs non-interactively and calls host-provided tools ("code mode").

## Task
Fetch the metrics `cpu`, `mem`, `disk`, `net` and `gpu`. A call that fails with code UNAVAILABLE is transient and may succeed if repeated: retry it immediately, making at most 4 attempts in total for that metric. Any other error code is permanent: do not retry it. Print one line per metric in the order listed above: `<name> ok <value> attempts=<n>` if it succeeded, or `<name> failed <code> attempts=<n>` if it did not, where n is the number of calls made for that metric. Finish with a line `total=<sum of the values of the metrics that succeeded>`.

## Tools
The script runs as an ES module with Node.js 22 (`node script.mjs`), so top-level `await` works; only built-in Node modules are available. The tools are async functions on a global object named `tools` (no import needed); each returns a Promise. Results are plain JavaScript values decoded from JSON. If a call fails, its Promise rejects with a `ToolError` (a global `Error` subclass) that has string properties `code` and `message`.

```ts
type MetricValue = {
  name: string;
  value: number; // integer
};

/** Reads the current value of a named metric. Fails with code UNAVAILABLE (transient) or NOT_FOUND (permanent). */
tools.fetch_metric(name: string): Promise<MetricValue>;
```

## Output
Print the final answer to stdout (for example with `console.log`), and nothing else. Output written to stderr is ignored. Surrounding whitespace is ignored; everything else must match exactly. The script is killed after 10 seconds.

Reply with only the complete script in a single fenced code block.
