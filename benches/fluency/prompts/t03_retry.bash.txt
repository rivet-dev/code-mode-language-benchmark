Write a bash 5.2 script for the task below. The script runs non-interactively and calls host-provided tools ("code mode").

## Task
Fetch the metrics `cpu`, `mem`, `disk`, `net` and `gpu`. A call that fails with code UNAVAILABLE is transient and may succeed if repeated: retry it immediately, making at most 4 attempts in total for that metric. Any other error code is permanent: do not retry it. Print one line per metric in the order listed above: `<name> ok <value> attempts=<n>` if it succeeded, or `<name> failed <code> attempts=<n>` if it did not, where n is the number of calls made for that metric. Finish with a line `total=<sum of the values of the metrics that succeeded>`.

## Tools
The script runs as `bash script.sh` with GNU bash 5.2. Besides bash builtins you may use standard command-line utilities (coreutils, grep, sed, awk) and jq 1.7; do not run other language interpreters such as python, perl or node. Each tool is a command on PATH that takes its parameters as positional arguments. On success it prints its result as one line of JSON to stdout and exits with status 0. On failure it prints nothing to stdout, prints one line of JSON `{"code": "...", "message": "..."}` to stderr, and exits with status 1.

```text
MetricValue: {"name": string, "value": integer}

fetch_metric NAME
    Reads the current value of a named metric. Fails with code UNAVAILABLE (transient) or NOT_FOUND (permanent).
    Prints: MetricValue (JSON)
```

## Output
Print the final answer to stdout (for example with `echo` or `printf`), and nothing else. Output written to stderr is ignored. Surrounding whitespace is ignored; everything else must match exactly. The script is killed after 10 seconds.

Reply with only the complete script in a single fenced code block.
