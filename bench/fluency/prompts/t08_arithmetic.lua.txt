Write a Lua 5.5 script for the task below. The script runs non-interactively and calls host-provided tools ("code mode").

## Task
Convert every expense to EUR: divide its amount by the rate of its currency; amounts in EUR need no conversion. For each category, sorted by category name, print `<category> <total in EUR with exactly 2 decimals>`. Then print `TOTAL <sum of all expenses in EUR with exactly 2 decimals>` and `MAX <id of the expense with the largest EUR amount> <that EUR amount with exactly 2 decimals>`. Sum the unrounded converted amounts and round only when printing.

## Tools
The script runs with Lua 5.5 and the standard libraries only. The tools are synchronous functions in a global table named `tools`, set up by a prelude before the script starts (no `require` needed). Results are Lua values decoded from JSON: objects become tables with string keys, arrays become sequences starting at index 1, and JSON null becomes nil (the field is absent). If a call fails, the function raises an error whose value is a table with string fields `code` and `message`; catch it with `pcall`.

```lua
---@class Rates
---@field base string always "EUR"
---@field rates table<string, number> units of each currency per 1 EUR; EUR itself is not listed

---@class Expense
---@field id string
---@field category string
---@field amount number in the expense's currency
---@field currency string ISO code, e.g. "USD"

---Current exchange rates.
---@return Rates
function tools.get_rates() end

---All expenses.
---@return Expense[]
function tools.list_expenses() end
```

## Output
Print the final answer to stdout (for example with `print` or `io.write`), and nothing else. Output written to stderr is ignored. Surrounding whitespace is ignored; everything else must match exactly. The script is killed after 10 seconds.

Reply with only the complete script in a single fenced code block.
