Write a JavaScript (Node.js 22) script for the task below. The script runs non-interactively and calls host-provided tools ("code mode").

## Task
Probe every host returned by `list_hosts`. If the language can run calls concurrently, run the probes concurrently with at most 3 in flight at any moment; otherwise run them one at a time. Then print the hosts whose status is not 200, one per line as `<host> <status>`, sorted by host name, followed by a final line `healthy=<number of hosts with status 200> max_latency=<largest latency_ms among hosts with status 200>`.

## Tools
The script runs as an ES module with Node.js 22 (`node script.mjs`), so top-level `await` works; only built-in Node modules are available. The tools are async functions on a global object named `tools` (no import needed); each returns a Promise. Results are plain JavaScript values decoded from JSON. If a call fails, its Promise rejects with a `ToolError` (a global `Error` subclass) that has string properties `code` and `message`.

```ts
type ProbeResult = {
  host: string;
  status: number; // integer
  latency_ms: number; // integer
};

/** Names of all hosts. */
tools.list_hosts(): Promise<string[]>;

/** Checks one host; takes about 0.3 seconds. The service allows at most 3 probe calls in flight at once: a probe call made while 3 are already in flight fails with code RATE_LIMITED, and after that every later probe call also fails with RATE_LIMITED. */
tools.probe(host: string): Promise<ProbeResult>;
```

## Output
Print the final answer to stdout (for example with `console.log`), and nothing else. Output written to stderr is ignored. Surrounding whitespace is ignored; everything else must match exactly. The script is killed after 10 seconds.

Reply with only the complete script in a single fenced code block.
