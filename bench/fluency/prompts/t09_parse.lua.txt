Write a Lua 5.5 script for the task below. The script runs non-interactively and calls host-provided tools ("code mode").

## Task
Parse the log. Each non-empty line is `<timestamp> <LEVEL> <component>: <message>`, optionally followed by a space and `{key=value key=value ...}` at the end of the line. Timestamps, levels and component names contain no spaces; messages contain no braces; keys and values contain no spaces, braces or `=`. Ignore empty lines. For each component with at least one ERROR line, print `<component> errors=<number of ERROR lines> codes=<distinct values of the code key on its ERROR lines, sorted, joined with commas>`, sorted by component. Then print `slowest <component> <took>` for the line (any level) with the largest `took` value, where took looks like `342ms`.

## Tools
The script runs with Lua 5.5 and the standard libraries only. The tools are synchronous functions in a global table named `tools`, set up by a prelude before the script starts (no `require` needed). Results are Lua values decoded from JSON: objects become tables with string keys, arrays become sequences starting at index 1, and JSON null becomes nil (the field is absent). If a call fails, the function raises an error whose value is a table with string fields `code` and `message`; catch it with `pcall`.

Print the final answer to stdout (for example with `print` or `io.write`), and nothing else. Output written to stderr is ignored. Surrounding whitespace is ignored; everything else must match exactly. The script is killed after 10 seconds.
