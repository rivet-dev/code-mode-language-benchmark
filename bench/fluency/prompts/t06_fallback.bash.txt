Write a bash 5.2 script for the task below. The script runs non-interactively and calls host-provided tools ("code mode").

## Task
For each user ID returned by `list_user_ids`, in that order, look the user up with `get_profile`. If that call fails with code NOT_FOUND, look the user up with `get_legacy_profile` instead: the display name is `<first> <last>` and the email is `mail`, or `-` when mail is null. If `get_profile` fails with any other code, do not fall back. Print one line per user: `<id> | <display name> | <email> | <source>` where source is `primary` or `legacy`, or `<id> | unresolved | <code of the last error>` when the user could not be resolved. Finish with a line `resolved=<n> unresolved=<m>`.

## Tools
The script runs as `bash script.sh` with GNU bash 5.2. Besides bash builtins you may use standard command-line utilities (coreutils, grep, sed, awk) and jq 1.7; do not run other language interpreters such as python, perl or node. Each tool is a command on PATH that takes its parameters as positional arguments. On success it prints its result as one line of JSON to stdout and exits with status 0. On failure it prints nothing to stdout, prints one line of JSON `{"code": "...", "message": "..."}` to stderr, and exits with status 1.

```text
Profile: {"id": string, "display_name": string, "email": string}

Name: {"first": string, "last": string}

LegacyProfile: {"uid": string, "name": Name, "mail": string or null}

list_user_ids
    IDs of the users to resolve.
    Prints: array of string (JSON)

get_profile USER_ID
    Looks a user up in the primary directory. Fails with code NOT_FOUND if the user is not there, or with another code (for example PERMISSION_DENIED).
    Prints: Profile (JSON)

get_legacy_profile USER_ID
    Looks a user up in the legacy directory. Fails with code NOT_FOUND if the user is not there.
    Prints: LegacyProfile (JSON)
```

## Output
Print the final answer to stdout (for example with `echo` or `printf`), and nothing else. Output written to stderr is ignored. Surrounding whitespace is ignored; everything else must match exactly. The script is killed after 10 seconds.

Reply with only the complete script in a single fenced code block.
