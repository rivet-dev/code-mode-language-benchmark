Write a JavaScript (Node.js 22) script for the task below. The script runs non-interactively and calls host-provided tools ("code mode").

## Task
Fetch invoice `INV-2041` and print it in exactly this layout. Line 1: `Invoice <id> for <customer>`. Then one line per invoice line: the description left-aligned and padded with spaces to 14 characters, the quantity right-aligned in 3 characters, one space, then the line total (quantity × unit price) in dollars with exactly 2 decimals, right-aligned in 9 characters. Then three summary lines, each with the label left-aligned and padded to 18 characters followed by the amount in dollars with exactly 2 decimals right-aligned in 9 characters: `Subtotal` (sum of line totals), `Tax` (subtotal × tax_bp / 10000, rounded to the nearest cent) and `Total` (subtotal + tax).

Example of the layout (made-up values):
```
Invoice INV-1 for Example Co
Pen             2      2.50
Paper pack     10     45.00
Subtotal              47.50
Tax                    2.38
Total                 49.88
```

## Tools
The script runs as an ES module with Node.js 22 (`node script.mjs`), so top-level `await` works; only built-in Node modules are available. The tools are async functions on a global object named `tools` (no import needed); each returns a Promise. Results are plain JavaScript values decoded from JSON. If a call fails, its Promise rejects with a `ToolError` (a global `Error` subclass) that has string properties `code` and `message`.

```ts
type InvoiceLine = {
  description: string;
  quantity: number; // integer
  unit_price_cents: number; // integer
};

type Invoice = {
  id: string;
  customer: string;
  tax_bp: number; // integer, tax rate in basis points: 825 means 8.25%
  lines: InvoiceLine[];
};

/** Fetches one invoice. Fails with code NOT_FOUND for an unknown id. */
tools.get_invoice(invoice_id: string): Promise<Invoice>;
```

## Output
Print the final answer to stdout (for example with `console.log`), and nothing else. Output written to stderr is ignored. Surrounding whitespace is ignored; everything else must match exactly. The script is killed after 10 seconds.

Reply with only the complete script in a single fenced code block.
